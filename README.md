# hokago-day-service

放課後等デイサービス向けの「きろく」共有アプリです。児童ごとに、トイレの時間・3段階の調子・昼食の摂取量・水分補給量・自由メモを記録し、スタッフ全員のスマホ・PCにリアルタイムで共有されます。

サーバー管理が不要な構成です（静的サイト + Firebase Firestore）。

## セットアップ手順（初回のみ）

### 1. Firebaseプロジェクトを作る
1. https://console.firebase.google.com を開く（無料のGoogleアカウントでOK）
2. 「プロジェクトを追加」→ 名前を入力（例: hokago-day-service）→ 続行
3. Google Analyticsは無効のままでOK →「プロジェクトを作成」

### 2. 匿名ログインを有効にする
1. 左メニュー「構築」→「Authentication」→「Sign-in method」タブ
2. 「匿名」を選び、有効化して保存

これにより、URLとFirebaseの設定を知っているスタッフだけがアプリを使える状態になります（パスワード入力は不要）。

### 3. Firestore Databaseを作る
1. 左メニュー「構築」→「Firestore Database」→「データベースを作成」
2. 本番環境モードを選択、リージョンは `asia-northeast1`（東京）を推奨
3. 作成後、「ルール」タブを開き、このリポジトリの `firestore.rules` の内容をそのまま貼り付けて「公開」

### 4. ウェブアプリを登録し、設定値を取得
1. プロジェクトの概要ページ →「</>」（ウェブアプリを追加）アイコンをクリック
2. アプリ名を入力（何でもOK）→ Firebase Hostingの設定は不要なのでチェックを外す → 登録
3. 表示される `firebaseConfig = { apiKey: ..., ... }` の中身をコピー
4. このリポジトリの `firebase-config.js` を開き、`YOUR_API_KEY` などのプレースホルダーを実際の値に書き換えて保存

### 5. 公開する（GitHub Pages）
1. GitHubのこのリポジトリで Settings → Pages を開く
2. Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
3. 数分後、`https://bonukun1021.github.io/hokago-day-service/` でアクセスできるようになります

公開後は、スタッフ全員でこのURLをブックマークすれば、全員の端末でリアルタイムに記録が共有されます。

## 使い方
- 初回アクセス時に右上の「記録者を設定」から自分の名前を入力（端末ごとに保存されます）
- 児童チップから対象の子どもを選択し、「＋ 管理」から児童の追加・削除ができます
- トイレ・調子・昼食・水分はボタンをワンタップで記録、メモは自由入力
- 「きろく一覧」に今日の全記録が時系列で表示され、他のスタッフの記録もリアルタイムで反映されます
- 日付の◀▶で過去の記録を閲覧できます（過去日は記録の追加不可、閲覧のみ）

## データについて
- データはFirebase Firestore上に保存され、あなたのFirebaseプロジェクトのみがアクセスできます
- `firebase-config.js` の値はアプリを動かすための公開識別子であり、実際のアクセス制御は Firestore のセキュリティルール（匿名ログイン必須）で行っています
